# AXS15231B ESP LCD driver snapshot

This directory contains the AXS15231B `esp_lcd` implementation and shared touch base from Waveshare's Arduino example repository, commit `def6edd0b6e1925ed09702eed01a2f181afdf8c1` (`09_LVGL_V8_Test`). The source files identify Espressif Systems as copyright holder and SPDX-License-Identifier Apache-2.0; the complete license text is in `LICENSE`.

The currently published Espressif component registry has an Apache-2.0 `espressif/esp_lcd_axs15231b` release at 2.1.0, while newer releases have changed license metadata to Custom. This snapshot is pinned to the known Apache-2.0 Waveshare source commit above; it is not represented as the separately versioned Espressif 2.1.0 source. It is a PlatformIO-local library because PlatformIO does not automatically resolve IDF Component Manager manifests in this Arduino project.
